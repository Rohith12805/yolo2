1. DATASET
--------------------------------------------------------------------------------
Dataset name:
Road Damage Dataset (RDD2020 / RDD2022 - India Subset)

Original Raw Dataset:
  - Total number of images: 7,706 images
  - Training images: 6,164 images (80% split)
  - Validation images: 1,542 images (20% split)
  - Testing images: Evaluated on the 1,542 validation images

Augmented Dataset (Utilized from Run 6 onward):
  - Training set expanded by 2x via offline domain-specific data augmentation
    (pavement glare/rain reflection simulation, lighting & contrast shifts,
    shadow gradients, HSV jitter, and perspective camera pitch transforms).
  - Augmented Training images: 12,328 images
  - Validation images: 1,542 images (strictly unaugmented to ensure unbiased evaluation)
  - Total Dataset Size: 13,870 images

Damage classes detected:
Final Production Model (3 Classes):
  - D00: Longitudinal Crack (Wheel mark crack)
  - D20: Alligator Crack (Mesh / Fatigue crack)
  - D40: Pothole / Rutting / Bump
(Note: Initial training phases 1-4 also included D10: Transverse Crack, which
 was removed in the 5th run to resolve label ambiguity and maximize detection accuracy).

YOLOv11n (Nano variant - 2.59M parameters, 6.5 GFLOPs)

Number of epochs:
50 epochs per training phase (Run 5 -> Run 6 -> Run 7 -> Run 8)

Image size:
640 x 640 pixels (App inference also operates smoothly at 512 x 512)

Training platform:
Other (Kaggle Notebooks Cloud GPU) for fine-tuning phases; initial runs on Local PC

GPU used:
2x NVIDIA Tesla T4 GPUs (Dual GPU, device: 0,1 on Kaggle)

4. METHODOLOGY & TECHNICAL BREAKDOWN ACROSS RUNS 6, 7, AND 8
--------------------------------------------------------------------------------
To achieve the 53.2% mAP@0.5 benchmark and push Pothole detection past 80%, we
structured the advancement into three distinct 50-epoch optimization stages:

STAGE 1: RUN 6 (50 Epochs) - DATA AUGMENTATION & SURFACE DIVERSITY
------------------------------------------------------------------
- Hypothesis: Real-world road detection struggles with diverse illumination,
  wet asphalt, and variable camera mounting heights.
- Action Taken: Expanded the training partition by 2x (from 6,164 to 12,328
  images) by introducing domain-specific augmentations:
    * Asphalt glare and dynamic shadow mapping.
    * HSV color jittering to simulate morning, midday, and overcast daylight.
    * Perspective angle transforms to represent different vehicle hood heights.
- Outcome: Model generalization improved substantially; overall mAP@0.5 rose
  from 46.32% to 48.75%, with Pothole accuracy advancing to 75.20%.

STAGE 2: RUN 7 (50 Epochs) - LEARNING RATE OPTIMIZATION & LOSS REBALANCING
--------------------------------------------------------------------------
- Hypothesis: Fixed linear learning rate decay causes gradient bouncing near
  local minima, while default loss weights undershoot irregular crack boundaries.
- Action Taken:
    * Lowered base learning rate to 0.005 and activated a Cosine Annealing
      schedule (cos_lr: true) for smooth asymptotic convergence.
    * Increased Box loss gain (box: 8.0, up from 7.5) and adjusted Distribution
      Focal Loss (DFL: 1.5) to heavily penalize sloppy crack perimeter bounds.
- Outcome: mAP@0.5 climbed from 48.75% to 51.15%, while strict overlap accuracy
  (mAP@0.5:0.95) advanced to 22.65%, tightening bounding boxes significantly.

STAGE 3: RUN 8 (50 Epochs) - MOSAIC DEACTIVATION & SALIENCY PEAK (FINAL MODEL)
------------------------------------------------------------------------------
- Hypothesis: Synthetic mosaic cut-lines introduce border noise in the final
  convergence phase, hindering precision on delicate crack fissures.
- Action Taken:
    * Implemented close_mosaic: 10, disabling mosaic augmentation for the last
      10 epochs to train purely on natural, full-scale dashcam perspectives.
    * Maintained ground-plane spatial priors (flipud: 0.0, fliplr: 0.5).
- Outcome: The model hit its peak performance:
    * Overall mAP@0.5 reached 53.18%.
    * Potholes (D40) reached 80.50% mAP@0.5 (81.5% true positive rate on normalized CM).
    * Precision achieved 58.42% and Recall reached 49.15%.
    * Checkpoint weights/best.pt deployed as the primary detection model.
